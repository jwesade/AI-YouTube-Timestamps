Placeholder for the Next.js 15 frontend — the public Deutschlandkarte aller Padel-Courts.

**Status:** Wird in Woche 2 aufgebaut, sobald die ersten echten Daten aus `packages/ingest` vorliegen.

- MapLibre GL JS (Open-Source-Karte)
- Tailwind CSS
- Supabase JS Client (read-only, über `anon`-Key)

Deployment: Vercel, Preview-URL pro Pull Request.
